SHIV TEXTILES BILLING APP - FIXED VERSION

Files:
- index.html: complete app
- sw.js: service worker with a new cache version to avoid showing the old broken app

Install/update on GitHub:
1. Open your repository: shiv-textiles-billing-v4-
2. For each file, open the existing file and use Edit (pencil/three-dot menu).
3. Replace its entire contents with the matching file from this package, then Commit changes.
   If using GitHub mobile, you can also use Add file > Upload files and upload these files, then commit. If GitHub says a file already exists, edit the existing file instead.
4. Wait for GitHub Pages to deploy.
5. Reopen the site and refresh. If the old screen remains, clear the site's Chrome cache or open in an Incognito tab.

Important:
- This app saves bills/products in this browser on this device using localStorage.
- Do not clear browser site data unless you have exported/recorded your data.
- The default catalogue has sample prices. Edit them to match your actual shop prices before use.
- Print / Save as PDF is available from the bill view.

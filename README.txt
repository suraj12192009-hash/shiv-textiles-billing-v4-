SHIV TEXTILES BILLING APP
=========================

This is a free offline-first web app that can be installed on Android.

EASIEST SETUP:
1. Create a free GitHub account if you don't already have one.
2. Create a new PUBLIC repository named: shiv-textiles-billing
3. Upload index.html, manifest.json and sw.js.
4. In GitHub: Settings -> Pages -> Deploy from branch -> main -> /(root) -> Save.
5. Open the Pages URL on your Android phone in Chrome.
6. Chrome menu -> Add to Home screen / Install app.
7. The app then works like an app and stores bills/products on that phone.

IMPORTANT:
- Data is stored locally in the browser/device.
- Use Settings -> Export backup regularly.
- PDF: Save Bill & Print -> Android/Chrome print dialog -> Save as PDF.
- This version does not automatically sync between phones.
- GST is a calculator field. Use your own applicable tax/invoice rules.
